# FlatWorldFix 1.0.0 (NeoForge 1.21.1)

First release of the NeoForge line. Same behaviour as the Forge 1.20.1 release 1.0.0, ported to
Minecraft 1.21.1: a world created as Superflat (or another selected world type) stays that type even
when a datapack such as Terralith overrides the overworld dimension, and stays that way on reload.

- Requires NeoForge 21.1.265 or later 21.1 (Java 21). Mod id `flatworldfix` is unchanged.
- Adapted to 1.21's `WorldDimensions` and baked-registry handling; the selected-world marker is
  carried by object identity between the two.

Baseline and provenance: branch `neoforge-1.21.1` started at `f872a379b2a87ee9584fe9ed3f7206a7b954dc01`
(Forge main, the `v1.0.0` line), which is the pack's installed baseline. Details are in
`.ci/port-provenance.json` and the release manifest.

Verified headless: unit tests, release jar check, and one dedicated-server proof that a fresh
Superflat world saves as flat with all three dimensions. Not yet run against a 1.21.1 Terralith jar.
